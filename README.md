# brain-tumor-mri-study
Project Overview:
  This independent study explores how machine learning can be applied to the classification of brain MRI images. The goal is to learn about the technical foundations of machine learning and CNNS, then to investigate their performance on a publicly available brain MRI dataset.

Research Goals:
- Learn Python and the tools used in machine learning
- Understand how neural networks and CNNs classify images
- Develop and evaluate an image-classification model
- Analyze model performance, errors, and limitations
- Investigate considerations such as dataset quality, bias, and the potential role of AI in medical diagnoses

Tools and Technologies
- Python
- Visual Studio Code
- Google Collab
- Git and GitHub
- NumPy, Matplotlib, scikit-learn, and PyTorch

Notes: This is an educational research project. The model is not intended for clinical diagnosis or medical decisions
